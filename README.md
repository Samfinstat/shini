# Еврошина и Аршина — отчёты по продвижению

Единый отчёт по SEO двух сайтов и контекстной рекламе arshini.ru.

## Файлы

- `index.html` — актуальная версия отчёта.
- `reports/2026-10-07/index.html` — исходный срез за 01.08–07.10.2026.
- `AGENTS.md` — правила последующих обновлений.

Отчёт открывается в современном браузере. Есть два входа: клиент и специалист. Пароли переданы владельцу отдельно и не сохраняются в репозитории. Содержимое зашифровано; внутренний разбор доступен только с паролем специалиста.

В режиме специалиста можно изменять комментарии и план, просматривать клиентский вид и скачивать обновлённый HTML. После изменения локального файла он должен быть загружен в репозиторий. Автоматического импорта Excel в HTML нет.

## Обновления

Новые выгрузки обрабатываются при подготовке следующего отчёта. Обновлённый отчёт сохраняется в `index.html`, версия на дату отчёта — в `reports/YYYY-MM-DD/index.html`. Исходный срез сохраняется без изменений. История правок доступна в коммитах Git.

## Доступ

Репозиторий `Samfinstat/shini` создан владельцем как публичный. Отчёты хранятся в зашифрованном виде; пароли и открытые исходные выгрузки сюда не загружаются. Размещение файлов в репозитории само по себе не включает GitHub Pages и не создаёт клиентскую веб-ссылку.
